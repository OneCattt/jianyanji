# 提交入驻申请时确认并锁定邀请归属

2026-10-20 需求调整第一轮确认：分享链接提供候选邀请关系，提交入驻申请时向申请人展示直接邀请人及归属主理人，申请人确认且服务端验证资格后锁定。采用申请时明确确认，便于处理用户先后打开多个分享链接的情况，使申请人与品牌方对本次关系有共同依据。

提交后的修改须由后台授权人员办理并保留操作记录。第二轮 Q14 确认申请店主必须通过有效代理邀请，不开放无邀请人申请店主的路径。

第二轮 Q15、Q17 确认主理人之间保留直接邀请关系，各自主理人名下店主独立归属；上级邀请人不自动获得另一主理人名下店主的收益或订单查询权限。获批变更归属仅影响后续新订单，历史已付款订单及其未结算奖励继续使用原归属；未付款申请或订单须重新确认关系。

第三轮 Q22、Q23 确认游客入驻主理人和店主升级主理人须由有效主理人邀请；升级重新确认本次关系并保留原店主入驻历史。升级不自动带走原先邀请的店主，既有店主仍归原主理人，新邀请店主归升级后的新主理人；既有店主变更归属仍走授权调整。

第三轮 Q25 确认主理人仅可查看本人直接邀请的其他主理人的名单及入驻状态，不开放其本人订货、团队订单或资金信息。

第四轮 Q26 确认主理人资格撤销时，由品牌方指定有效主理人接管其名下店主并记录交接，店主自身资格保留；接管后新订单归新主理人，历史已付款订单及奖励继续按原归属核算和冲回，不自动转给原主理人的邀请人。原主理人不再享有被撤销资格的新增权益，若恢复有效店主身份则仅按店主资格开展业务。

第四轮 Q27 确认首批代理通过授权后台人工核验开通，作为免邀请初始化特例，解决尚无有效邀请人时的启动问题。已有代理按真实资格登记，新入驻者关联真实产品包收款和交付，不因登记身份补发历史积分或奖励；后续普通入驻仍须有效邀请。开通及交接操作均保留人员、原因和依据。
