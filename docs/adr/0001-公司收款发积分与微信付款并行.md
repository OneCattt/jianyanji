# 公司收款发积分与微信付款并行

> 2026-10-20 后续确认：首期所有资金收付均在线下办理，微信付款和微信原路退款要求已取消，以 [V2.1 需求规格](../requirements/清欣简妍肌首期需求规格说明V2.md)及最新确认记录为准。下文保留历史决策依据；公司核款、积分订货及资格规则继续适用。

> 2026-10-20：下文产品包仅采用公司转款的限制已由 [ADR 0004](0004-产品包双渠道付款与核款后激活身份.md) 替代；普通商品双支付、公司转款发积分及退款规则继续适用。

所有购买身份均可在小程序直接付款；代理另可向品牌公司转款，由指定工作人员核实到账并按 1 元对应 1 积分发放后订货。用户已确认同一身份两种支付方式的商品价格一致，因此公司收款、积分发放与商品订单支付需要分别记录，不能把代理身份解释为必须预充值，也不能把小程序商品付款直接计作积分充值。

未使用积分对应款项的退款由品牌方人工审核并保留实际退款及积分扣回记录；商品订单退款按原支付方式处理。这样保留品牌现有的公司收款业务，同时允许用户直接购买，并使资金与积分来源可以逐笔追溯。

入驻产品包首期通过向公司转款购买，货款只用于交付对应商品，不另发等额可消费积分。产品包全部退款后取消该次入驻取得的身份，历史订单和积分记录保留；部分退货由品牌方审核是否仍满足身份条件。普通积分订单退款退回且尚未再次消费的积分，可在核实原公司收款未超退的前提下申请人工退现金。

确认来源：2026-10-19 会话中的角色及下单流程说明，以及对 Q1、Q3、Q4、Q5、Q8、Q10、Q14、Q18、Q19 的确认。
