# 区分零售佣金与订货收益并按收益人登记入驻奖励

2026-10-20 第二轮 Q11、Q13 确认首期新增顾客小程序零售订单的销售归属和零售佣金：店主 30%、主理人 65%；代理本人折扣订货不再发本人零售佣金，代理自行线下零售利润不由系统另发。该区分使小程序实际零售成交奖励与代理订货后的自行经营利润分别有明确含义，避免将折扣和佣金重复支付。

店主直接邀请新人购买店主包时，直接邀请店主和其归属主理人各得 500 元；主理人直接邀请新人购买店主包时，该主理人得 1,000 元，不另叠加 500 元。一笔产品包业务可以对应不同收益人的奖励，须分别关联来源、结算及退款冲回，原先仅按新加入者身份区分两档固定奖励的规则不再适用。

保留人员确认登记、系统提供核算依据、线下实际结算及已付奖励抵扣追回。8,000 元主理人入驻奖励、5% 业绩奖励和其他未完整确认政策关闭。

第三轮 Q18～Q20 确认销售归属按顾客每笔零售订单分别确认并在提交时锁定，不永久绑定顾客；无销售代理的顾客也可零售购买，不发代理佣金。零售佣金以普通商品实付货款为基数，不含运费，且不叠加归属主理人的订货收益。福利品所有身份统一福利价，不参与零售佣金或主理人订货收益。

第三轮 Q21 确认普通商品按身份折扣计算单价并四舍五入到分，再按实际两档价差乘数量核算店主订货收益。35%作为折扣对应的价差说明，真实核算取历史价格快照，以避免单独按比例取整与实际两档价格之间出现分币差额。

本决定部分替代 ADR 0002 中仅提供两类奖励及原两档入驻奖励的范围限制，其人工登记与结算原则继续适用。
