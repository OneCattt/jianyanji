# 首期采用人工奖励核算与结算

用户已确认首期上线必须发放代理奖励，因此首期必须提供奖励来源、对象、金额、核算依据、实际结算与退款冲回记录。首期由品牌方人工核算并结算，不引入自动计算引擎或自动打款，保留现有人工核对和公司转账流程。

首期仅提供直接邀请人的入驻奖励、归属主理人的店主订货收益，不做多层奖励。奖励由公司线下转账，后台留存收款人、金额及付款凭证；代理在小程序查询本人明细，不提供在线提现。

入驻奖励按新加入者身份设两档固定金额；店主订货收益按商品原成交价与当时主理人价的差额乘数量核算，不含运费，微信和积分支付同规则。对应商品收货完成、售后期结束且无待处理售后后可结算，每月集中转账一次，具体档位金额和月结日期在上线前配置。

登记奖励不代表实际付款。订货退款冲回退货商品对应的原收益，产品包退款按原货款退款比例冲回原入驻奖励；全退冲回全部。已付奖励优先抵扣同一人后续应结算奖励，不足部分人工追回并持续记录，没有实际抵扣或收回的金额不能标为已追回。奖励与订货积分分别记录，后续改价或调整奖励金额不重算历史来源业务。
