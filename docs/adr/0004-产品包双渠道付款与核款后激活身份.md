# 产品包双渠道付款与核款后激活身份

2026-10-20 需求调整第一轮确认：入驻产品包支持小程序微信付款和公司转款，资格、协议和邀请归属在付款前确认；核实真实到账后激活身份，不再追加独立运营审批。该决定兼顾小程序直接购买与公司现有转款收款方式，将原先付款后的资格判断提前，避免到账后仍因入驻资格不明而等待审批。

微信渠道以服务端核实的真实支付结果为依据，公司转款以财务核实到账为依据；两种方式均须关联本次申请、对应实物订单及实际收款，产品包款不额外发积分。普通商品仍支持原微信／积分付款，积分充值仍仅采用公司转款核款。

本决定替代 ADR 0001 中产品包仅限公司转款的限制，以及旧规格中到账后单独审批身份的流程。全额退款撤销该次身份、部分退款人工判断及历史记录保留继续沿用；奖励分配见 ADR 0006。

第二轮 Q16、第三轮 Q24 确认店主可另购完整 19,800 元主理人包升级，不抵扣原店主包货款。升级包全部退款后恢复仍有效的原店主资格；原店主资格也无效时回到游客。须分别保留各次资格及来源，不能将当前身份简单替换为游客而抹掉仍有效的旧资格。
