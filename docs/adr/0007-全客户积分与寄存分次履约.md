# 全客户积分支付与寄存分次履约

2026-10-27 用户确认：所有客户先私域充值、后台核款发积分，普通商品、固定权益包和运费仅使用积分；余额不足须先补充值。充值本身不激活身份，扣积分购买固定包后激活身份并立即取得身份价。普通SKU三档价格独立，不再按固定折扣运行。福利品、邀请归属和奖励收益人规则保留。

本决定替代V2.1中仅代理积分、普通货款/产品包直接核款、固定7折/3.5折、退款自动撤销身份、整单收货售后期后才能结算的规则；历史已付款交易依据不重算。新退款不自动关身份，关闭资格独立办理并校验团队交接。权益包消耗仅为统计。

寄存按原订单与SKU批次保留所有权，支付时扣可售，提货只扣寄存。多订单同用户同地址可合并一次提货，一次运费。纯新购配送免费；新购满1000并带寄存免费；否则有寄存时普通顾客/2980档免费，19800档按原寄存成交分摊货款满1000免费，否则10元。赠品不凑门槛。运费扣积分。

取消未发货提货仅退本次运费并释放寄存占用；商品退款另行审核、退原积分批次。赠品退回量由后台核定。佣金及订货收益按签收部分可结算，仍人工月结，退款按原来源冲回追回。寄存按上海支付日加12个日历月，到期当日有效，过期不清零不回收，后台可办理或延期。
