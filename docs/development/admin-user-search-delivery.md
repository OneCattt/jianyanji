# 后台用户搜索与标准控件交付

## 发布范围

后台独立用户编号输入统一使用 `AdminUserSelect`，按昵称、手机号、ID进行服务端分页搜索，显示脱敏手机号、有效身份和编号。覆盖寄存、核款、退现金、资格和邀请归属、财务导出及审计用户对象。归属与接管仅可选择有效19800店主；直接邀请人限有效店主；奖励收益人保持原交易候选范围。原业务接口继续校验写入权限与归属。

参考 `pos-medical-insurance-center` 的公共查询表单封装，沿用已有 Ant Design Vue，引入公共筛选栏和主题文件，统一控件高度、间距及小屏换行；寄存日期替换为公共日期组件，修复复选框文字错位。切换用户清除原用户钱包、原收款、地址、批次和关系选择。组件约定见 [后台 Ant Design 文档](admin-ant-design.md)。

仅提交和部署后端服务与管理后台。工作区的小程序及其既有改动保留，不纳入本次发布。
