# 后台商品快捷搜索与配置页面交付

## 范围

- 活动套餐、入驻产品包统一使用服务端分页商品规格搜索；新增明细默认未选商品，不再默认绑定 SKU 1。
- 品牌种草内容以商品名称搜索、多选关联，最多 10 个；编辑草稿不修改列表中原关联数组。
- 寄存台账支持搜索商品规格筛选，包含停用规格；历史转寄存和人工提货搜索原订单明细或该用户的原寄存批次，显示成交名称、原订单及可用数量。写入仍按原来源校验归属、占用、数量、运费和幂等。
- 订单和售后搜索支持成交快照中的商品名、规格名，不按现价或现名称重算历史。
- 套餐与提醒分为两个页签。品牌资料、商品规格、入驻产品包和课程权益移除重复卡片/分组框，统一标题、分隔线、网格、复选框对齐和保存区；配送及奖励配置沿用相同表单规范。

- Vue/TypeScript 类型检查和完整 Vite 构建通过；Vite 仍提示既有主包超过 500kB，此次不扩展代码分包范围。
- 13 项前端行为回归通过，覆盖跨页、搜索防抖及旧响应、停用回显、选择保留、多选上限、失败重试、用户范围切换、卸载与实际保存参数，包含已有库存编辑保护回归。

- 实际 Vue 页面浏览器检查：套餐搜索、选择和保存成功；内容关联多选成功；人工提货只显示指定用户原批次；品牌、商品规格、产品包、课程与提醒配置检查。1440px、390px 套餐页面无横向溢出。截图保存于本地 `artifacts/admin-product-search/`，不作为生产真实业务验收。
