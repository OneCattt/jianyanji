# 后台 Ant Design 重构

## 范围与组件约定

后台使用 Ant Design Vue 4.2.6，适配项目现有 Vue 3。统一中文语言、品牌红、表格、输入框、按钮、导航、弹窗和浮动消息。

覆盖工作台、品牌内容、课程权益、商品分类、品牌资料、入驻、订单发货、售后、配送、收款积分、积分退现金、奖励结算、用户、工作人员、操作记录共 15 个页面，以及图片上传、资格归属办理、业务导出。

- `web/main.ts` 统一主题及按需注册实际使用的组件。
- `AdminDialog.vue` 使用 AntD Modal，统一宽度、滚动区、操作栏及异步操作后的键盘焦点。
- `AdminForm.vue` 使用 AntD Form 承载现有中文字段校验，保留必填、格式和范围约束；支持数值框和日期、选择器的校验与聚焦。
- `AdminSelect.vue` 使用 AntD Select 展示和搜索，保留原 option 的字符串、数值类型及 change 事件契约。
- `AdminDatePicker.vue` 使用 AntD DatePicker，保留日期、月份、到账时间字符串格式；手机端日期与时间上下排列。
- `FeedbackToast.vue` 统一使用 AntD message；成功和失败反馈不占据页面或表单布局。

## 操作路径

- 内容列表支持标题、摘要和发布状态筛选；保存草稿、审核、发布、下架分别处理。
- 入驻申请作为日常工作入口；资格核验与归属调整放在可展开的独立区域。
- 订单、入驻与售后支持筛选、分页和明细查看；需要操作原因、真实到账确认的流程继续保留相应约束。
- 奖励按登记、付款核实、追回分组；来源核算先展示可读摘要，原始记录按需展开。
- 列表为空时展示对应说明；宽表格在自身区域滚动，手机端使用抽屉导航。

## 验证记录

使用本地浏览器、模拟接口检查界面；未向真实业务接口写入数据。接口模拟只能验证前端交互和提交契约，不能证明微信支付、银行到账或真实退款已联调通过。

- 15 个页面、35 类弹窗，覆盖 1440×1000、792×439、390×844；共 151 项页面、弹窗和字段错误布局检查。
- 检查横向溢出、滚动区、操作栏跨列、末尾字段遮挡、Escape 关闭及运行错误、组件参数警告。
- 三种尺寸验证错误消息可见且不改变弹窗位置、尺寸；模拟审核失败后重试成功，消息自动消失。
- 模拟收款提交验证：12.99 元提交为 1299 分、用户编号为数值、渠道保留字符串、北京时间转换为原接口要求的 ISO 时间；未确认真实到账时阻止提交。
- 模拟月结提交验证结算月份、所选奖励及实际收款人；检查数值范围、售后原订单选择、审计筛选。
- 检查登录必填、错误后重试、财务账号权限菜单、手机导航及日期时间浮层。
- 执行 `npm run typecheck`、`npm run build` 和 `git diff --check`。

本地界面截图及布局检查结果位于忽略提交的 `artifacts/dialog-layout/`。

构建包含 AntD 公共组件及后台模块，会提示单个 JavaScript 文件超过 500 kB；当前构建成功，该提示不代表运行错误。
