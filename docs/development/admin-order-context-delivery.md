## 行为

- 订单详情按订单摘要、配送办理、成交商品、地址与支付、原订单直接发货记录排列。商品展示成交快照、赠品及购买/已发/剩余寄存/新购待配送/可直接发货数量。支付时间显示北京时间，流水按需展开。
- 订单内打开配送详情，标题明确来自哪张订单，关闭或返回后仍是原订单，列表筛选及页码保留；不再跳转寄存与提货菜单。
- 订单和寄存页面共用 `AdminPickupDrawer`；实际配送地址、跨订单的完整配送商品、审核和物流均以配送单为准。审核、发货、取消及运费退款仍使用原服务端接口及权限。
- 配送操作使用固定底栏；提交失败保留输入，成功立即用服务端返回的最新单据更新，随后刷新原订单和列表。刷新失败明确提示“办理已成功”，旧履约数量停用，重载成功恢复。
- 无后端源码、数据库迁移或配置变化，无小程序变动。
