## 修改

订单与发货页仅保留顶部状态切换：全部、待支付、待发货、运输中、寄存中、已完成、已退款、已关闭。搜索栏删除重复状态下拉，支付摘要统一为“已支付/待支付”。

后台新增 `fulfillment` 查询条件，按实际包裹、有效配送申请和寄存余额，在计数与分页之前筛选；卡片主状态优先级为运输中、待发货、寄存中。待发货包含待审核配送和待出库，有在途包裹时优先归运输中，签收后仍有寄存则回到寄存中。

原 `status` 参数及财务积分支付记录的查询口径保持原语义。没有修改订单持久化状态、资金库存写入、数据库迁移或配置，没有修改小程序。
