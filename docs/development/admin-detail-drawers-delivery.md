# 后台复杂办理侧边栏交付

2026-10-28，订单“查看与处理”从列表底部详情改为直接打开右侧抽屉，同时统一入驻申请、奖励追溯、钱包查询和提货详情；提货审核、驳回、取消及发货入口固定在底栏。

按追加要求，复杂新增、编辑和查看复用公共抽屉：商品/品牌/种草内容、图片裁切、工作人员权限、入驻产品包、核款/发货、奖励结算、退款、寄存/身份及配送配置。简短确认与分类等小表单保留Modal；页面原有直接配置和就地展开保留。

`AdminDrawer`统一宽度、标题、内容滚动、关闭区和键盘焦点；`AdminDialog`在wide或显式drawer时复用抽屉，保留原表单、权限、接口及提交契约。子窗口打开或提交上传期间禁止关闭父详情，关闭后保留列表位置，失败后表单内容保留。

## 验证与发布方法

- 浏览器使用实际Vue页面与模拟HTTP，验证订单、入驻、奖励、钱包、提货，长列表后段立即展示、关闭保持位置、记录切换、1920/1024/390像素及1259×570矮窗口内部滚动；覆盖复杂新增/编辑、图片裁切、嵌套Esc及提交期间关闭限制，模拟失败后内容保留。脚本：`scripts/check-admin-detail-drawers.mjs`。
- 执行类型检查、19项用户/商品搜索回归。从实际提交导出源码，独立生产构建及JDK8 Maven verify。后端源码沿用当前提交的既有实现，随管理前端一同重新构建部署。
- 无数据库迁移和配置变化，V1～V14须与线上一致。部署前暂停API、备份数据库/旧应用/配置；失败仅回退应用，业务数据不整库回灌。发布后核对产物哈希、服务、匿名权限、迁移、全表行数与资金汇总。
- 本地模拟不替代生产真实账号业务验收；公网访问独立探测。小程序未发布，工作区已有小程序改动不纳入此次提交。
