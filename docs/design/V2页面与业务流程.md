# V2 页面与业务流程

本稿按 2026-10-20 用户最新确认更新为 V2.1 目标流程：首期实际资金收付均线下办理，保留积分订货。付款、退款界面与服务端已按任务 36 收口，当前验证见 [线下交易实施说明](../development/v2-offline-transactions.md)；下方历史截图保留为调整前参考。截图来自专用隔离数据库，不代表正式品牌数据或微信真机视觉验收。

## 小程序页面

| 入口 | 页面及关键操作 | 状态与反馈 |
| --- | --- | --- |
| 首页 | 身份产品包、商品、已发布品牌内容推荐、课程权益入口 | 未登录可浏览；未配置显示真实空态 |
| 商城 | 普通／福利品、适用身份价、购物袋、线下付款指引／积分订货 | 报价统一；销售代理逐单确认；线下订单待财务核款后可发货 |
| 种草空间 | 品牌已审核图文／短视频、详情、商品关联、朋友及朋友圈分享 | 草稿、下架内容不可公开访问；视频失败可重试 |
| 我的→代理入驻 | 产品包对比、邀请核验、协议和地址、确认提交、线下付款指引、资格历史 | 财务核实到账后激活；仅提交凭证不代表到账；关系变化重新确认 |
| 我的→邀请伙伴 | 本人真实随机分享码及入驻路径 | 仅有效代理，登录后保留候选关系 |
| 我的→订单售后 | 本人订单商品、数量、原因提交及进度查询 | 受理不代表退款；服务端核定数量金额，失败不显示成功 |
| 我的→团队 | 归属店主、限定订货信息、本人收益、直接邀请主理人名单与状态 | 仅有效主理人；不包含电话地址、钱包、凭证或他人收益 |
| 我的→课程权益 | 身份权益介绍、成长权益、联系与报名指引 | 按有效身份选取，不提供报名管理或学习系统 |

底部导航为首页、商城、种草空间、我的。原生页面继续使用现有品牌排版及胶囊／底部安全区处理。

## 后台页面

| 页面 | 首期目标操作 |
| --- | --- |
| 产品包与入驻 | 实物明细与分摊、到账激活、首批存量核验／新申请、团队接管、关系调整 |
| 商品与分类 | 普通零售价及计算后身份价、统一福利价及商品类型 |
| 品牌种草内容 | 草稿编辑→审核→发布；关联商品、图文／视频、下架与逻辑移除 |
| 课程成长权益 | D／C／B分别配置介绍、权益、联系方法和报名指引 |
| 奖励与结算 | 按来源展示不同收益人，人工登记、可结算检查、月结、冲回与同人追回 |
| 财务收退款 | 区分普通订单货款、产品包和积分充值，核实线下到账；登记线下退款实际结果及凭证 |
| 对应业务导出 | 沿查询权限和白名单字段，金额单位清楚，操作留痕 |

## 入驻与升级

```mermaid
flowchart TD
  A[有效代理分享] --> B[申请人核验并确认邀请与归属]
  B --> C[确认资格 协议 地址和产品包]
  C --> D[提交申请并固定来源]
  D --> E[线下向公司付款]
  E --> G[财务核实公司到账并登记凭证]
  G --> H
  H --> I[品牌仓发货与本人收货]
  J[授权首批新入驻核验] --> C
  K[真实存量资格核验] --> L[留存资格依据 不补造收款积分奖励]
```

## 实际退款与资格恢复

```mermaid
flowchart TD
  A[用户申请或后台受理] --> B[审核 原商品金额和数量]
  B --> C{需撤销主理人资格}
  C -->|是| D[先指定有效团队接管人]
  C -->|否| E[退货验收 线下实际退款或原积分退回]
  D --> E
  E --> F{实际退款结果}
  F -->|失败或未明| G[保留原交易 核查补偿 不冒认成功]
  F -->|成功| H[原积分批次或资金记录同步]
  H --> I[该次资格保留或撤销]
  I --> J{升级资格撤销后原店主是否有效}
  J -->|有效| K[恢复店主]
  J -->|无效| L[游客]
  I --> M[主理人团队按指定计划交接]
  H --> N[各原收益人奖励分别冲回]
  N --> O[已付形成原收益人欠款 同人抵扣或实际追回]
```
