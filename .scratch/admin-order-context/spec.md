# 订单内配送办理与详情层级

目标：订单详情优先展示履约状态、待办配送和成交商品；配送办理在订单上下文内完成，返回后保留订单、筛选及分页。后台仅考虑桌面端。

- 订单与寄存页面复用配送详情、审核、发货、取消和运费退款组件；沿用原权限和服务端接口。
- 配送单可跨原订单，展示完整商品及实际配送地址；原订单地址与本次配送地址区分。
- 商品使用成交快照；原订单待发货计算继续扣除寄存、配送占用及售后占用。
- 支付时间转北京时间，流水折叠。原订单直接发货与配送单物流分别显示。
- 写入成功立即使用返回状态；刷新失败明确说明已成功并停用旧履约数量，防止重复办理。
- 验证：相关回归、类型检查、桌面浏览器实际操作、最终提交产物构建与发布核对。模拟写入只在本地内存接口执行。

替代旧规则：订单内“办理本次配送”不再切换到寄存与提货菜单。
