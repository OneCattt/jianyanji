# 13: 未用积分对应款项退现金

**What to build:** 代理经客服人工申请退回未用积分对应的公司转款，后台占用积分、核实原款并登记实际现金退款，代理能核对余额和结果。

**Blocked by:** 08：订货转款确认、发积分与钱包查询；11：积分商品订单退款

**Status:** ready-for-human

## 验收条件

- [x] 后台受理申请并保留代理、原公司收款、申请金额及原因；包括商品退款已退回且尚未再次消费的积分，不开放奖励提现。
- [x] 审核同时校验可退积分和原收款剩余未退现金，扣除办理中占用；已消费积分、产品包款及其他人的收款不能作为退款来源。
- [x] 申请获准办理时占用相应积分和可退款项额度，办理中积分不能继续消费或再次申请现金退款。
- [x] 记录线下实际收款人、金额、付款时间及凭证；实际成功才扣回对应积分并完成现金退款记录，审批通过不是退款成功。
- [x] 驳回或明确失败时释放对应占用；结果未明时保留待核查状态，核实后办理，避免款项已退但积分重新可花。
- [x] 原公司收款、积分发放、消费、商品退积分和现金退回可逐笔追溯，累计现金退款不超过原实际收款。
- [x] 代理可查看本人可用余额、占用及退款结果；关键操作留痕、失败可按业务和请求编号处理，重复确认不得二次扣回。
- [x] 验证 1,000 积分办理退 600 后仅可用 400，成功扣回、失败释放、并发消费与退款互斥，以及订单退回积分仍受原现金未退额限制。
