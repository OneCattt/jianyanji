# 09: 积分支付商品订单

**What to build:** 有效代理以已有积分支付整笔普通商品订单，实时看到扣减与订单结果，并使用既有发货流程。

**Blocked by:** 05：微信付款与待付款订单处理；08：订货转款确认、发积分与钱包查询

**Status:** ready-for-human

## 验收条件

- [x] 店主、主理人可在普通商品结算时选择积分，游客不能使用代理积分支付；同身份商品价与微信付款一致。
- [x] 创建待付款订单不扣积分；用户最终确认积分付款时才校验可用余额并扣减，展示本次扣减及剩余余额。
- [x] 整单仅一种支付方式，不混合支付；积分不足时说明差额、提供公司转款说明，原支付结果明确后才可选择微信整单支付。
- [x] 扣积分、积分流水、支付记录和订单待发货结果保持一致；重复或并发付款只扣一次，不超扣、不超卖。
- [x] 同一订单微信和积分支付相互约束；微信确认中不能再扣积分，已付积分不能又发起有效微信付款。
- [x] 本人订单和钱包展示对应支付及消费记录，并能追溯消耗的公司收款来源；保留店主原成交价、原主理人价和归属依据。
- [x] 验证重复点击、两订单并发争用余额、微信支付未明时切换被拒绝，以及成功扣积分后发货至确认收货的完整路径。
