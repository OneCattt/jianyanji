# 28: 用户在线提交售后

**What to build:** 用户从本人订单选择商品、数量及原因提交售后并查看真实处理进度。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

## 验收条件

- [x] 本人订单合法商品数量可申请，服务端核算可退额度与金额。
- [x] 越权、超量、重复及并发申请受控，申请不等于退款。
- [x] 后台复用审核、退货验收与实际退款，未退商品正常履约。
- [ ] 按 V2.1 及任务 36 验证：现金线下退款并登记真实结果，积分退回原批次，产品包按原收款核验并登记线下退款；失败和未决状态真实展示。原勾选仅对应调整前渠道实现。

## 共同约束

- 以用户最终确认V2为业务依据，复用既有实现，保留原01～18证据和当前工作区改动。
- 交付包含本任务必要的数据、服务、用户／后台入口和验证；历史快照不重算，不虚构缺失资格或资金依据。
- Java显式使用JDK8；新增业务表使用统一六项审计字段，业务数据仅逻辑删除。
- 财务／异步失败保留追踪号与业务键，需补偿状态可查询；外部未决不得当成功。
- 窄范围前端做相关检查；本地替代测试不等于真实微信、银行或真机验收。
