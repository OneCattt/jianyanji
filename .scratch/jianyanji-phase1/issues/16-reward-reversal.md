# 16: 退款对应的奖励冲回

**What to build:** 品牌方按来源业务实际退款登记原奖励冲回，代理查看冲回明细，未付奖励减少待付金额，已付部分形成待收回依据。

**Blocked by:** 10：普通商品售后与微信原路退款；11：积分商品订单退款；12：产品包退款与代理身份处理；14：入驻奖励登记与本人查询；15：店主订货收益登记与本人查询

**Status:** ready-for-agent

## 验收条件

- [ ] 冲回关联原奖励、原订单或产品包及实际退款结果，保留原因、金额及操作人；退款失败或仅申请售后不冒充已退款冲回依据。
- [ ] 店主订货退款按原退货商品单位收益和实际退款数量冲回，不按当前价差计算，不包含运费。
- [ ] 入驻奖励按原产品包累计已退货款占原货款的比例核定累计应冲回额，再扣此前已冲回金额；运费不进入比例。
- [ ] 金额计算保留精度，登记至分并按四舍五入处理；累计冲回不能超过原奖励，全退冲回原奖励剩余全部金额以补齐尾差。
- [ ] 重复登记或并发处理同一退款不重复冲回；未付部分减少待付额，已付部分明确记录尚待收回，不能记作现金已追回。
- [ ] 后台和本人奖励明细能核对原奖励、分次冲回、剩余可付及待收回金额；结算需核对已完成退款是否已处理奖励，防止漏处理后多付。
- [ ] 首期由品牌方人工核对登记，不增加自动奖励核算或自动追回款项。
- [ ] 验证价差收益 60 元退一件冲回 20 元；产品包货款 1,000 元、原奖励 200 元，先退货款 250 元冲回 50 元，再退 250 元再冲回 50 元，全退累计 200 元。
- [ ] 验证分次退款取整尾差、全退补齐、重复冲回及已付未追回与未付减少待付的区分。
