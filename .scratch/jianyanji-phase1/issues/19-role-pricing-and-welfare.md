# 19: 普通商品折扣、福利价与订货收益

**What to build:** 从后台定价、商城报价到线下付款／积分订货统一价格和收益依据。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

## 验收条件

- [x] 普通商品按零售价计算店主7折、主理人3.5折，单价四舍五入到分，福利品全身份同价。
- [x] 零售价100.01元时店主70.01、主理人35.00，单位订货收益35.01；福利品和运费不计收益。
- [x] 普通／福利品混合订单两支付方式同价，商品页、购物袋、结算和实际成交一致。
- [x] 订单保存原价格与商品类型，改价不影响旧单；按原商品部分退款冲回，保留历史数据。
