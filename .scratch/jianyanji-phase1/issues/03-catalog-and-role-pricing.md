# 03: 商品管理与商城浏览

**What to build:** 品牌方维护可售商品、规格、库存和身份价格，购买者按分类浏览并查看当前购买身份适用的商品信息。

**Blocked by:** 01：登录、身份识别与后台权限

**Status:** ready-for-agent

## 验收条件

- [ ] 后台维护分类、商品图片说明、规格、库存、上下架状态；停用或移除保留历史交易可引用的信息。
- [ ] 按规格维护零售价、店主价、主理人价，精确表达金额和数量单位；采用价差收益的商品主理人价不得高于店主价。
- [ ] 未登录访客和已登录非代理用户看到游客价格；有效店主、主理人看到各自身份适用价格，不因支付方式预先改变商品价。
- [ ] 商城可按分类浏览，商品详情展示规格、图片说明、可购买状态及库存情况，并可选择有效规格和数量。
- [ ] 必要价格未配置或规格不可售时不能使用示例金额或静默以零出售，购买者得到明确提示。
- [ ] 价格、库存和上下架调整记录操作者和时间；调整不改变已成立订单的成交信息。
- [ ] 验证同一商品以游客、店主、主理人访问时价格正确；不可售规格不能继续购买，未经授权不能维护商品。
- [ ] 核对商城与商品详情的必要手机布局，不为普通静态展示追加与实现重复的测试。
