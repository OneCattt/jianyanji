# 15: 店主订货收益登记与本人查询

**What to build:** 品牌方根据店主已成交订单原价差人工登记归属主理人的订货收益，主理人在本人奖励中核对商品来源及金额。

**Blocked by:** 06：后台发货与用户确认收货；09：积分支付商品订单

**Status:** ready-for-human

## 验收条件

- [x] 人工核算使用各商品原实际成交单价减当时主理人订货单价再乘原购买数量，按原订单归属确认收款主理人，不使用当前价格或当前关系替代。
- [x] 运费不计收益；微信和积分订单同一口径，积分按 1∶1 对应货款，不因支付方式变更奖励。
- [x] 保留订单、商品规格数量、原单价依据、归属、登记金额和操作者，后台可核对人工核算依据；同一来源不得重复登记收益。
- [x] 收益仅归属该店主的归属主理人，不自动生成其他层级奖励；首期不建设自动收益生成引擎。
- [x] 主理人仅查看本人奖励来源、金额和未到期等状态，未达到结算条件不可显示已结算；不暴露他人无关订单资料。
- [x] 后续退款仍可按原商品单位收益及数量追溯，后续商品改价、身份变化或归属变化不重算原收益。
- [x] 验证店主单价 100 元、原主理人价 80 元、数量 3、运费 10 元时人工登记依据为 60 元；主理人价改为 70 元后原收益仍为 60 元，两支付方式一致。
