# 20: 资格来源留存与首批代理核验

**What to build:** 用户可查看有真实依据的各次资格，授权品牌人员可办理首批核验开通。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

## 验收条件

- [x] 保存各次资格及真实来源，迁移现有有效资格而不覆盖旧交易。
- [x] 首批存量代理依据真实资格办理，不要求重购，不补造收款、积分或历史奖励。
- [x] 新入驻首批代理仍须对应真实产品包收款与交付；后续普通入驻要求邀请。
- [x] 核验限授权人员，记录原因、依据、人员与时间，用户端展示真实身份。

## 共同约束

- 以用户最终确认V2为业务依据，复用既有实现，保留原01～18证据和当前工作区改动。
- 交付包含本任务必要的数据、服务、用户／后台入口和验证；历史快照不重算，不虚构缺失资格或资金依据。
- Java显式使用JDK8；新增业务表使用统一六项审计字段，业务数据仅逻辑删除。
- 财务／异步失败保留追踪号与业务键，需补偿状态可查询；外部未决不得当成功。
- 窄范围前端做相关检查；本地替代测试不等于真实微信、银行或真机验收。
