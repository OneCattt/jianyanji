# 27: 逐单销售归属与零售佣金

**What to build:** 顾客每单确认销售代理，工作人员据原商品货款登记零售佣金并结算退款。

**Blocked by:** 19：普通商品折扣、福利价与订货收益；26：多收益人入驻奖励及结算追回

**Status:** ready-for-human

## 验收条件

- [x] 每单确认并锁定销售代理、原身份和比例，不永久绑定顾客，不自动用入驻邀请人替代。
- [x] 无代理正常零售，代理折扣自购无本人零售佣金。
- [x] 普通货款C30%、B65%，不含运费及福利品，不叠加同单主理人订货收益。
- [x] 退款按原商品实际范围冲回，支持分次取整、已付欠款、同人抵扣与追回。

## 共同约束

- 以用户最终确认V2为业务依据，复用既有实现，保留原01～18证据和当前工作区改动。
- 交付包含本任务必要的数据、服务、用户／后台入口和验证；历史快照不重算，不虚构缺失资格或资金依据。
- Java显式使用JDK8；新增业务表使用统一六项审计字段，业务数据仅逻辑删除。
- 财务／异步失败保留追踪号与业务键，需补偿状态可查询；外部未决不得当成功。
- 窄范围前端做相关检查；本地替代测试不等于真实微信、银行或真机验收。
