# 18: 已付奖励抵扣与人工追回

**What to build:** 已付奖励发生冲回后，品牌方优先从同一人后续可结算奖励中抵扣，剩余人工追回，后台与代理端都能核对尚未收回款项。

**Blocked by:** 17：奖励到期检查与月度线下结算

**Status:** ready-for-agent

## 验收条件

- [ ] 待收回记录关联原已付奖励及冲回来源，展示原金额、累计抵扣、人工实收及剩余未收回额，不因登记冲回直接归零。
- [ ] 仅抵扣同一人后续已满足结算条件的奖励，不扣其他人的奖励、不扣订货积分，不提前占用未到期收益冒充已追回。
- [ ] 每次抵扣同时关联原待收回记录和本次结算奖励，应付、抵扣、实付及剩余欠款一致，抵扣不能超欠款或超本次可结算奖励。
- [ ] 后续奖励不足时实付可为零，差额持续待追；有剩余应付款时月结仅转账扣除抵扣后的实付金额。
- [ ] 人工追回登记实际收款金额、时间、原收款人、凭证及操作人，核实到账后才减少待收回额；承诺归还或处理申请不能冒充到账。
- [ ] 重复或并发抵扣、人工实收与结算竞争不会重复扣回或超收，失败及未明结果可追查处理。
- [ ] 代理本人奖励明细显示相关冲回、抵扣、人工追回及剩余款项，品牌方可持续查询尚未收回对象。
- [ ] 验证待收回 100 元、后续可结算 80 元时抵扣 80 元、实付 0 元、待收回 20 元；之后实际追回 20 元才结清，重复操作金额不再变化。
- [ ] 验证存在欠款时必须先抵扣再月结，不对无关代理抵扣；保留全部操作和资金依据供核对。
