# 08: 订货转款确认、发积分与钱包查询

**What to build:** 代理根据公司说明转款，品牌方核实订货款后按 1∶1 发积分，代理查看钱包和可追溯流水。

**Blocked by:** 07：产品包入驻、转款审核与商品交付

**Status:** ready-for-human

## 验收条件

- [x] 有效代理查看真实公司收款资料、转款备注和客服说明，首期不提供小程序在线微信充值。
- [x] 品牌方登记代理、实际金额、到账时间、收款账户标识、原流水、用途和凭证，核实订货款后才发积分。
- [x] 两类代理均按 1 元对应 1 积分发放，不赠送、不过期；同一原收款首期对应一人，不能同时作为产品包收款。
- [x] 发放结果、余额和积分流水一致，重复或并发确认同一到账记录只发放一次；失败不得显示为已发。
- [x] 代理只能查看本人积分余额、可用余额及发放流水，后台可按代理或原收款追查结果。
- [x] 积分纠错通过有来源、有原因、有操作者的纠正记录处理，不无痕改余额、不制造无来源积分；已消费部分不能靠扣成负数消除资金差额。
- [x] 收款、发放及后续消费保留可关联的原始来源，为商品退积分和未用积分退现金提供依据。
- [x] 验证一笔 1,000 元到账只发一次 1,000 积分、产品包流水不能发积分、并发重复发放及本人钱包隔离；失败可按请求及业务编号追踪处理。
