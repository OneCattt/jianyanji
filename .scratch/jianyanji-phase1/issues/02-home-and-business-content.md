# 02: 首页与经营说明配置

**What to build:** 运营人员在后台更新品牌介绍、客服及经营说明，购买者在小程序首页和相关说明页面看到有效内容。

**Blocked by:** 01：登录、身份识别与后台权限

**Status:** ready-for-human

## 验收条件

- [x] 小程序底部提供首页、商城、我的；首页提供品牌介绍和首期已有能力入口，尚未实现或不在首期范围的功能不展示可点击入口。
- [x] 后台可维护品牌文字、必要图片、客服联系方式及购买说明，保存后购买端可读取当前有效内容。
- [x] 展示有效的公司收款及转款说明；具体收款用途和业务条件在产品包、积分业务中分别约束，不能把说明展示当成到账确认。
- [x] 维护内容有基本必填校验和修改留痕；没有真实资料时明确提示尚未配置，不用原型中的账号或示例内容冒充经营信息。
- [x] 配置调整不覆盖历史业务已保存的交易依据；普通内容维护不引入通用规则引擎。
- [ ] 验证一次后台修改后首页正确展示，检查未登录访问、手机文字可读性及安全区布局；无权限账号不能修改内容。
