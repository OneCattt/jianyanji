# 04: 购物袋、地址与订单确认

**What to build:** 购买者立即购买或从购物袋结算，维护自己的收货地址、核对运费和商品金额后生成可继续付款的订单，并保留成交依据。

**Blocked by:** 03：商品管理与商城浏览

**Status:** ready-for-human

## 验收条件

- [x] 支持立即购买、购物袋添加及勾选、多规格数量调整和移除；分别展示商品种类数、总件数及合计金额。
- [x] 用户只能维护本人的收货人、电话、地区、详细地址及默认地址；改地址或移除地址不改变已有订单地址。
- [x] 后台可维护首期固定配送范围、运费和发货说明；结算页清楚展示货款、运费及应付总额，区域不可配送时不允许下单。
- [x] 下单核验商品、规格、数量、上下架、库存和当前身份价格；价格变化需重新确认，前端传入金额不能替代后台依据。
- [x] 生成本人可查询的待付款订单，保存商品规格、数量、购买身份、成交单价、运费和地址；店主订单同时保存当时主理人单价及归属依据。
- [x] 待付款订单具有可追溯编号；仅创建订单不扣积分、不标记已付款，库存占用与释放在后续支付流程保持一致。
- [x] 配置变动或用户资料变动不会重写已保存交易依据；缺失必要配送或价格配置时说明原因。
- [x] 验证多商品结算金额、配送限制、下单前价格变化和历史地址价格保留，以及本人订单访问控制。
