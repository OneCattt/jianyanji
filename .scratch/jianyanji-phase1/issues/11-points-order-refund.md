# 11: 积分商品订单退款

**What to build:** 客服沿既有售后流程办理积分订单退款，实际可退积分返回原购买者钱包，并继续保留原公司收款来源。

**Blocked by:** 09：积分支付商品订单；10：普通商品售后与微信原路退款

**Status:** ready-for-human

## 验收条件

- [x] 积分商品订单复用客服受理、审核、退货验货及部分数量售后流程，用户可查询当前处理结果。
- [x] 按原积分支付和实际退款范围退回积分，不直接以现金办理商品退款，不按当前新价格重算。
- [x] 积分退回、退款结果和余额流水一致；部分退款不超过原支付剩余可退积分，重复和并发操作不多退。
- [x] 退款处理中不冒充积分已到账；实际到账后用户钱包和订单能核对同一退款，失败保留可查询处理状态。
- [x] 按原消费来源恢复对应的公司收款可追溯关系，区分退款退回且未再次消费的积分与已经消费的部分。
- [x] 退积分与可售库存分别处理；未退商品保留交付关系，实际退回商品经验货后才决定库存。
- [x] 验证部分退积分、全部退积分、重复退款、失败后恢复及跨收款来源消费后的退款关联，不把退积分当成已退现金。
