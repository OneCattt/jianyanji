# 14: 入驻奖励登记与本人查询

**What to build:** 品牌方按新加入者身份对应的固定金额人工登记直接邀请人的入驻奖励，代理在我的奖励中查询来源及待结算金额。

**Blocked by:** 07：产品包入驻、转款审核与商品交付

**Status:** ready-for-agent

## 验收条件

- [ ] 后台维护邀请店主、邀请主理人两档固定奖励，实际金额由品牌方提供；缺失参数不能以示例或静默零值代替。
- [ ] 每次入驻采用当次审核成立时保存的奖励金额和归属依据，后续档位调整不追改原来源业务。
- [ ] 工作人员根据申请、有效产品包收款及交付依据人工核算登记，保留来源、新加入者目标身份、直接邀请人、原奖励金额和操作人。
- [ ] 奖励归直接邀请人，不自动改为归属主理人，不产生多层奖励；同一来源同一奖励不得重复登记发放。
- [ ] 登记奖励与付款分别记录，尚未满足收货及售后条件时显示未到结算期，不能把人工登记视为实际已付。
- [ ] 小程序我的奖励仅展示本人的来源、金额和当前状态，避免泄露无关人员资料；后续结算和冲回可沿此明细查询。
- [ ] 奖励与订货积分钱包分开，首期无在线提现、自动奖励生成或自动转积分。
- [ ] 验证两档身份奖励、邀请人与归属不同、改档位不改历史、重复来源登记及本人奖励隔离。
