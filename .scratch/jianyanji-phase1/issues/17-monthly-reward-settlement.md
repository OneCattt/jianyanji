# 17: 奖励到期检查与月度线下结算

**What to build:** 品牌方核对可结算奖励，按月向代理线下转账并记录真实付款依据，代理查询实际结算结果。

**Blocked by:** 16：退款对应的奖励冲回

**Status:** ready-for-agent

## 验收条件

- [ ] 后台维护售后期和每月集中结算日期，明确当前结算月份和日期说明；缺失真实参数不能用示例默认值启用结算。
- [ ] 对应商品已确认收货、适用售后期结束且无待处理售后才可结算；入驻奖励还须核实审核通过、有效收款和产品包交付。
- [ ] 适用期限保留来源业务当时依据，后续配置变化不追改已成立业务；到期检查与人工登记奖励、实际付款分别呈现。
- [ ] 结算前核对退款和冲回后的剩余应付，不把已冲回部分或同一奖励重复纳入结算；存在待核实的已付冲回款时不能直接全额再付款。
- [ ] 记录结算月份、奖励来源、实际收款人、应付、抵扣、实付、付款时间及凭证，合计可核对；待付款和实际已付状态分开。
- [ ] 首期公司每月线下集中转账，由工作人员登记核实结果，不自动打款、不在线提现、不将奖励转为订货积分。
- [ ] 付款失败或待核实保留真实状态，必要时可查询补偿；重复提交或重复确认不重复记已付。
- [ ] 代理仅查看本人结算明细；后台核算及付款操作按授权执行并留痕。
- [ ] 验证未收货、售后期内、待处理售后不可结算，符合条件后月结登记付款成功可查；已退款未冲回业务不能多付。
- [ ] 后续抵扣能力接入后，月结应付、抵扣与实付保持一致；抵扣能力未交付时，有未处理待收回款的对象保持待处理，不能绕过扣回直接结清。
