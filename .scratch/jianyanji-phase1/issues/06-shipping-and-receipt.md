# 06: 后台发货与用户确认收货

**What to build:** 品牌方对已付款且允许履约的商品登记发货，购买者查看物流公司和运单号并确认收货，形成可复用的商品交付流程。

**Blocked by:** 05：微信付款与待付款订单处理

**Status:** ready-for-agent

## 验收条件

- [ ] 后台可按订单查看已付款、可发货的商品和数量，未付款商品不可发货；后续退款占用的商品数量也必须受发货校验约束。
- [ ] 登记物流公司、运单号、发货时间及操作人；错填纠正留存原因和操作记录。
- [ ] 订单列表和详情展示待发货、已发货、已完成等进度；用户可查看物流公司并复制运单号，首期不接实时物流轨迹。
- [ ] 购买者只能对本人符合条件的已发货订单确认收货；重复确认不重复推进履约记录，后台可查询收货完成时间。
- [ ] 履约按实际商品和剩余可交付数量处理，为后续部分退款保留未退商品的交付关系。
- [ ] 交付记录可关联普通商品订单及后续产品包业务；公司核实产品包收款后也能走该交付流程，不把产品包款伪造为微信付款。
- [ ] 验证未付款不可发货、正常发货至收货完成、重复确认及物流信息纠正；检查手机端查询与按钮安全区。
