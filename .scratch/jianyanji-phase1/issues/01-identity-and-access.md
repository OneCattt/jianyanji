# 01: 登录、身份识别与后台权限

**What to build:** 用户在小程序登录后查看真实有效身份，品牌方工作人员按授权进入后台；建立后续业务可复用的登录、本人数据访问和操作留痕能力。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

## 验收条件

- [x] 交付可运行的小程序与品牌方后台最小入口，记录启动方式及采用的技术方案；未登录仍可进入公开浏览入口，购买和个人业务查询需要登录。
- [x] 首次登录仍为游客 D；已存在的有效调肤店主 C、调肤主理人 B 登录后显示对应身份，不因登录生成代理资格。
- [x] 品牌方后台账号及功能授权与小程序购买身份分开管理；后台权限不自动给予代理价。
- [x] 用户可查看必要个人资料和联系方式；未授权请求不能读取或修改他人资料，不能通过更换业务编号绕过本人范围。
- [x] 管理者可授权和停用工作人员账号；关键操作可按业务对象查询操作人、时间、结果及原因，后续业务复用该能力。
- [x] 业务资料停用或移除采用逻辑删除并保留历史依据；采用 MySQL 时执行项目约定的审计字段、正常查询过滤及可重复写入约束，不使用物理删除消除冲突。
- [ ] 小程序身份信息及登录按钮清晰可读，不被微信顶部区域或底部安全区遮挡。
- [x] 验证新用户登录仍为 D、有效代理身份保留、后台越权及他人资料访问被拒绝；后续代理开通由入驻业务提供，不增加任意自助改身份入口。
