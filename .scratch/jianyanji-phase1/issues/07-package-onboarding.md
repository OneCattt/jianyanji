# 07: 产品包入驻、转款审核与商品交付

**What to build:** 申请人选择产品包并向公司转款，品牌方核实款项、审核代理身份和邀请归属并交付商品，申请人可查询办理结果。

**Blocked by:** 03：商品管理与商城浏览；06：后台发货与用户确认收货

**Status:** ready-for-human

## 验收条件

- [x] 后台维护店主、主理人的身份权益、入驻条件、产品包货款及具体商品规格数量；小程序可查看说明并提交目标身份申请。
- [x] 用户查看转款说明、申请进度、收款及交付状态和驳回原因；首期产品包只接受向公司转款，不使用微信支付或积分购买产品包。
- [x] 工作人员核实真实到账，登记申请人、金额、到账时间、收款账户标识、原收款流水、产品包用途及凭证；截图或申请提交本身不作为到账。
- [x] 同一公司收款有统一的可追溯用途标识，不能重复记作产品包款或再次发为订货积分；产品包款只对应实际商品交付。
- [x] 后台分别确认直接邀请人和归属主理人；没有邀请人或邀请人为店主时由品牌方指定归属主理人，两者允许不同，不进行多层自动绑定。
- [x] 核实入驻条件及有效收款后审核通过或驳回；只有通过才启用对应代理身份和价格，保留审核原因、操作者、时间和适用条件。
- [x] 申请成立时保留产品包货款、商品明细、目标身份、邀请归属和当时适用入驻奖励档位金额的依据，后续调整不能追改历史；所需实际参数由品牌方配置。
- [x] 确认收款后安排对应商品发货、查询运单并确认收货；身份审核与交付分别可查，审核通过不冒充已交付。
- [x] 验证无邀请人、店主邀请、重复确认收款、审核前后身份价格变化及整套收款交付路径；产品包到账不增加积分钱包余额。
