# 小程序隐私政策与同意处理

用户授权：2026-10-22「补齐 完整的隐私政策／隐私同意处理」。

## 范围与规则

- 按实际微信身份、手填资料与地址、订单核款、积分、代理关系、奖励、售后、访问日志及本地缓存编写政策，保留首期线下资金规则。
- 首页、商城、商品、品牌图文、课程与产品包说明可匿名浏览；登录前统一进入政策页，由用户主动勾选并同意；拒绝不发起 wx.login、私有 API 或业务写入。
- 接入微信 getPrivacySetting、openPrivacyContract、agreePrivacyAuthorization、onNeedPrivacyAuthorization、requirePrivacyAuthorize，不把本地标记视为微信平台授权。
- 保存当前版本、同意时间及运营主体；政策版本变化不复用旧同意。首次同意前校验后台真实运营主体及隐私联系方式已配置。
- 设置页可查看、撤回同意；撤回清理本机登录及业务选择缓存、退出并清空页面栈，在途旧请求不得恢复登录或回写隐私数据。退出登录与撤回同意分开处理。
- 提供查阅、更正、删除、注销的人工申请入口；历史财务、订单依法保留，不能因撤回直接销毁交易或资格。
- 品牌后台可维护隐私主体及联系方式，旧请求省略字段保留原值，不引入数据库表或迁移。

## 验收

覆盖同意／拒绝／返回、微信授权失败、旧版本、已登录旧用户、商品快捷登录、地址与订单写入拦截、撤回后缓存和在途请求、匿名浏览；执行原生编译检查与相关回归。平台隐私指引配置、真实主体核对及微信真机验收单列。
