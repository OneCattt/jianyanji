# 清欣简妍肌 Logo｜清妍·初绽

## 设计方向

中央清露、舒展花瓣与下方肌肤弧线组成品牌符号，呼应护肤、滋养与东方肌肤管理美学。宋体风格字标延续项目现有气质。

## 品牌颜色

| 用途 | 色值 |
| --- | --- |
| 胭脂红（主色） | `#8D1724` |
| 米白（背景与反白） | `#F8F5EE` |
| 墨色（单色版本） | `#251D1A` |
| 暖金（页面辅助色） | `#9F7D58` |

## 文件使用

- `Logo设计提案.html`：可离线打开，切换横版、竖版、独立符号及底色，下载对应 SVG / PNG。
- `assets/logo-horizontal-*.svg`：横版图文组合，适合页面页头与品牌落款。
- `assets/logo-stacked-*.svg`：竖版图文组合，适合品牌展示、封面和海报。
- `assets/logo-mark-*.svg`：独立符号，适合小尺寸入口及头像。
- `assets/app-icon.svg`、`app-icon-light.svg`：深浅底小程序图标。
- 文件名 `red` 为胭脂红、`white` 为米白反白、`black` 为墨色。
- PNG：横版宽 2048px、竖版宽 2048px、独立符号 1024px，均为透明背景；小程序图标另有 1024px、512px 两种尺寸，使用实色背景。
- `assets/logo-preview.png`：1600×1000 展示图，不作为透明素材使用。

## 使用建议

保持等比缩放，四周留白建议至少为图形宽度的 1/4。深底使用反白版，浅底使用红色或墨色版。图文组合应确保中文清楚可读；窄小区域优先使用独立符号，避免英文副标缩得过小。

小程序图标使用方形原稿，圆角由平台裁切。建议优先上传 `app-icon-1024.png`。

字标采用宋体风格（Songti SC 转曲），图形与文字均为矢量路径，无字体运行依赖，未包含字体软件。已接入小程序首页、入驻页，后台登录页、侧栏，以及浏览器体验页与网站图标。小程序使用透明 PNG，后台使用 SVG，均从本地资源加载。

微信平台展示的小程序头像需在微信公众平台上传 `miniprogram/assets/brand/app-icon.png`，修改项目图片不会同步更新平台头像。

已验证 9 种组合切换、SVG / PNG / 图标下载以及 390px 手机宽度无横向溢出。SVG 可编辑，PNG 透明通道已检查。
